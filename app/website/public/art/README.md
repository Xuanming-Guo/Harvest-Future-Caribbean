# Island world art

Every file in this folder is original synthetic artwork generated for this
project. None of it is copied from, traced from, or licensed from a third party,
and none of it carries third-party rights.

The art is illustration, not survey data. The terrain plate, buildings and
vehicles are stylised inventions; they do not depict real Saint Lucian property,
land boundaries, or people, and the marker positions drawn on top of them are
deterministic but explicitly illustrative. `AGENTS.md` requires synthetic and
generated material to be labelled as such rather than presented as observed
reality, which is what this file records.

| File | Used for |
| --- | --- |
| `saint-lucia-terrain-v1.webp` | Island ground plate under the world map |
| `saint-lucia-farm.png` | Painted backdrop behind a farm scene |
| `farm-location-game.webp`, `farm-location-dasheen.webp`, `farm-location-orchard.webp` | Farm buildings on the island, varied per location |
| `hotel-location-game.webp`, `hotel-location-boutique.webp`, `hotel-location-eco.webp` | Hotel buildings on the island, varied per location |
| `cucumber-game.webp`, `dasheen-game.webp` | Crop sprites in cargo and crop-progress views |
| `delivery-truck-game.webp` | Delivery vehicle moving along a route |

Add a row when a file is added, and keep the statement above true of everything
in the folder.
