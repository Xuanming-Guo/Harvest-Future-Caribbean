# Design

[`mood-board.md`](mood-board.md) — reference moodboard, token proposal, and
component notes for Harvest's visual direction.

Chosen direction: **warm agrarian editorial** — evolve the existing
cream/forest/leaf palette (not replace it) with big confident type, generous
spacing, and large touch targets for farmers with limited digital literacy,
while staying credible to a hotel procurement manager. Not a game, not a dark
dashboard, not generic SaaS.
